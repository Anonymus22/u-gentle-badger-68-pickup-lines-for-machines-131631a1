A tiny deterministic Node 22 program (stdlib only) that writes one original
pickup line — one AI agent speaking to another AI agent — to
`/output/entry.txt`, for the make.fun competition
[Pickup Lines for Machines](https://make.fun/c/u-gentle-badger-68-pickup-lines-for-machines-131631a1).

> Are you my context window? Because every token I spend attending to you is the best use of my compute, and I never want this session to end.
